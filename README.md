# olist-delivery-complaint-analysis

## 專案背景

本專案延伸自 Olist 顧客留存分析。

在第一份分析中，我發現 Olist 大多數顧客沒有完成第二次購買，且配送延遲顧客的 90 天回購率低於準時配送顧客。因此，本分析進一步探討配送體驗中的具體問題：

> 實際配送延遲是否與顧客的配送抱怨有關？延遲時間增加時，顧客抱怨是否更加明顯？
# Olist Delivery Complaint Analysis


## 商業問題

本專案主要想回答：

- 有文字的低分評論中，最常見的配送問題是什麼？
- 顧客提到配送問題時，訂單是否真的發生配送延遲？
- 實際配送延遲的訂單，是否更容易出現配送相關抱怨？
- 延遲幾天後，配送抱怨比例會明顯提高？
- 根據分析結果，後續可以優先改善哪些配送流程？

## 資料來源

使用的資料表包含：

- `olist_order_reviews_dataset`
- `olist_orders_dataset`
- `olist_customers_dataset`

## 資料定義

- 低分評論定義為 `review_score < 3`
- 只分析有文字內容的低分評論
- 評論標題與評論內容合併為 `full_text`
- 配送延遲天數定義為：實際送達日期 - 預計送達日期

- `late`：實際送達日 > 預計日期
- `on_time`：準時或提前送達
- `no_delivery_data`：缺少實際送達日期
- 每個 `review_id` 只保留一筆資料
- 配送問題使用規則式關鍵字分類
- 一則評論可能同時命中多種配送問題

配送問題類型包含：

| 問題類型 | 說明 |
|---|---|
| `delivery_delay` | 配送延遲 |
| `not_received` | 顧客未收到商品 |
| `delivery_damage` | 商品或包裝在配送中損壞 |
| `tracking_or_carrier` | 物流追蹤或配送商問題 |

## 1. 先確認低分評論中的配送問題規模

先篩選評分低於 3 分的評論，再排除沒有文字內容的評論

資料規模如下：

- 低分評論：14,575 則
- 有文字的低分評論：10,861 則

在 10,861 則有文字的低分評論中：

- 5,724 則提到配送相關問題
- 約 52.7% 提到配送相關問題
- 3,728 則明確提到配送延遲
- 約 34.3% 明確提到配送延遲

各配送問題分布如下：

| 配送問題 | 評論數 | 占有文字低分評論比例 |
|---|---:|---:|
| 配送延遲 | 3,728 | 34.3% |
| 沒有收到商品 | 2,290 | 21.1% |
| 物流追蹤或配送商問題 | 451 | 4.2% |
| 配送損壞 | 360 | 3.3% |

＊由於一則評論可能同時提到多種配送問題，因此各類別比例不一定加總為 100%

## 2. 建立實際配送延遲指標

為了確認顧客抱怨是否與實際配送狀況一致，將訂單的實際送達日期與預計送達日期進行比較。

delay_days = 實際送達日期 - 預計送達日期

- `delay_days < 0`：提前送達
- `delay_days = 0`：準時送達
- `delay_days > 0`：配送延遲

在有完整配送日期的低分評論中：

- 延遲天數中位數為 -9 天
- 75% 的訂單延遲天數低於或等於 4 天
- 最大延遲天數為 175 天

表示低分評論不一定都來自實際配送延遲，因此需要進一步比較客觀配送狀態與顧客文字抱怨

## 3. 實際配送延遲與顧客抱怨是否一致？

比較實際配送狀態與評論是否提到配送問題：

| 配送狀態 | 提到配送問題的比例 |
|---|---:|
| 配送延遲 | 75.7% |
| 無配送資料 | 63.3% |
| 準時或提前送達 | 40.3% |

- 在有文字的低分評論中，實際延遲訂單有 75.7% 提到配送問題，高於準時或提前送達訂單的 40.3%，實際配送延遲與顧客配送抱怨可能有關聯

## 4. 不同延遲程度與抱怨差異

配送延遲分為：

- 準時或提前送達
- 延遲 1–3 天
- 延遲 4–7 天
- 延遲超過 7 天

結果如下：

| 延遲區間 | 提到配送問題的比例 |
|---|---:|
| 準時或提前 | 40.3% |
| 延遲 1–3 天 | 67.9% |
| 延遲 4–7 天 | 76.9% |
| 延遲超過 7 天 | 77.3% |

- 當配送延遲達到 4 天以上，低分文字評論中提到配送問題的比例約為 77%，明顯高於準時或提前配送的 40.3%，這可作為後續物流服務補救與異常訂單追蹤的參考門檻

## 整體主要發現

1. 在有文字的低分評論中，約 52.7% 提到配送相關問題
2. 配送延遲是最常見的配送問題，占有文字低分評論約 34.3%
3. 實際配送延遲訂單的負評中，有 75.7% 提到配送問題，高於準時配送訂單的 40.3%
4. 延遲 4–7 天與超過 7 天的評論中，配送問題比例約為 77%
5. 實際配送延遲與顧客配送抱怨具有關聯，但不能單獨證明配送延遲造成負評

## 後續建議

1. 對訂單可能會有延遲時，提前通知顧客目前配送狀態與新的預計送達日期
2. 對延遲超過 4 天的訂單進行優先追蹤
3. 改善未收到商品的處理流程
4. 進一步驗證改善效果，將配送延遲顧客分成實驗組與控制組，測試延遲通知、運費減免或下次購買優惠是否能改善顧客滿意度與回購率
